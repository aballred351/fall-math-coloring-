# Fall Math Coloring Studio 🍂

A free, no-login, student-friendly math coloring website. Students click picture sections, solve math problems to unlock them, pick colors, and **download a printable PDF** of their artwork.

## What's included
- 4 coloring pages: Pumpkin Patch, Autumn Tree, Thanksgiving Turkey, Acorn & Leaves
- 4 math difficulty choices: one-step equations, two-step equations, exponent rules, algebra challenge
- A different problem for each colorable section, with instant answer checking and hints
- Color palette plus a custom color picker
- Auto-saving progress in each student's browser per picture and math level
- **Direct PDF download** (landscape US Letter), and PNG export
- Works on Chromebooks, phones, and computers; no sign-in or database
- Entire app is one `index.html` file; no libraries, CDN, or build tools

## Put it on GitHub Pages (about 2 minutes)
1. Go to GitHub and create a **public** repository, e.g. `fall-math-coloring`.
2. Choose **Add file → Upload files**. Upload `index.html` from this folder. Commit the change.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)` and click **Save**.
5. Open the published link shown on the Pages settings screen. It is normally `https://YOUR-USERNAME.github.io/fall-math-coloring/`.

Share the Pages URL in Google Classroom. Students do not need GitHub accounts.

## Teacher notes
- Students can use **Start Over** to clear the current level/picture's progress.
- If a student changes Chromebook, signs in with a different Chrome profile, or clears local site data, progress does not follow them. Encourage PDF or PNG download when finished.
- The PDF button can also export partially completed pictures; the picture is complete when all sections are unlocked.
- For Algebra, some problems ask for a missing constant (marked in the prompt), and the rest ask for x.
- To use without the internet, download `index.html` and open it in Chrome. Some school-managed Chromebooks may restrict local file access; GitHub Pages is the easiest option.

All content is original and free to adapt for your classroom.
